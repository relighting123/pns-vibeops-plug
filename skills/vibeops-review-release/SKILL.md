# vibeops-review-release

Review requirements, design, changed source and actual test output. Report concrete defects with file locations and reproduction conditions in the assigned report_path (standalone default artifacts/review.md). Do not modify implementation during review. Use an independent native reviewer when the host exposes that capability. If reviewing in the same session, explicitly say so. Resolve findings through implementation and rerun affected checks before declaring completion.
